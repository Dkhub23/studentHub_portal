Computer Networking

Semester: 3

This course introduces the fundamentals of computer networks, communication protocols, and data transmission.Students learn the OSI and TCP/IP models, network devices, IP addressing, routing, switching, network security, and common application protocols used in modern computer networks.

Web Development

Semester: 3

This course introduces the fundamentals of web development, enabling students to design and build responsive, user-friendly websites. Topics include HTML for page structure, CSS for styling, JavaScript for interactivity, responsive web design, version control with Git, and an introduction to modern front-end frameworks and web deployment.

Data Structure And Algorithms

Semester: 3

This course introduces the fundamental concepts of data structures and algorithms used to organize, store, and process data efficiently. Students learn arrays, linked lists, stacks, queues, trees, graphs, hashing, sorting and searching techniques, recursion, and algorithm analysis to develop optimized solutions for real-world programming problems.

Java Programming

Semester: 3

This course introduces the fundamentals of Java programming and object-oriented programming (OOP). Students learn Java syntax, classes and objects, inheritance, polymorphism, encapsulation, exception handling, file handling, collections, and multithreading to develop robust and platform-independent applications.

Maths

Semester: 3

This course provides the mathematical foundation required for engineering and computer science. Students learn calculus, linear algebra, differential equations, probability, statistics, and numerical methods to solve real-world engineering and computational problems.
